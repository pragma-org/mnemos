# PRAGMA Quarterly Project Report Template

This is the suggested template for PRAGMA project quarterly reports under PDR-0006. Not all sections will be relevant to all projects. Any project may repurpose this for their own reporting.

Reports should be added to the PRAGMA board quarterly repo.

This template is meant to make reporting consistent and easy to review. It is not a substitute for PRAGMA statutes, PDRs or board decisions.

## 13. Pre-Submission Checklist

- [ ] Problems requiring board attention are clearly identified.
- [ ] Next planned steps are listed.
- [ ] Reflection and performance are included.
- [ ] Funding or sustainability risks are disclosed.
- [ ] Sensitive security details are not included in the public report.
